# 🤖 X Square Robot Track — HackLab Robotics x BRISA Hackathon Berlin

Welcome to our project repository for the **HackLab Robotics x BRISA Hackathon** in Berlin (November 21–22, 2026).

## 🎯 Challenge & Goal
In the **X Square Robot Track**, our goal is to design custom object manipulation tasks, test real-world everyday objects, and control the robot using the **X Square API**.

* **Focus:** Object sorting, grasping, and precise positioning
* **Test Objects:** Everyday office items (e.g., ballpoint pens for multi-object sorting & alignment tasks)
